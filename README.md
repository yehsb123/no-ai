# NO-AI

Claude Code가 한국어 글을 쓸 때 AI 티를 빼도록 하는 플러그인입니다. 설치하면 켜진 상태로 시작하고, 요청마다 규칙이 적용됩니다.

## 준비

- Claude Code
- git
- Python 3. 터미널에서 `python --version` 을 쳤을 때 버전이 나와야 합니다.

Windows에서 Python을 새로 설치할 때는 설치 첫 화면의 "Add python.exe to PATH"를 체크합니다. Mac은 `python3` 만 있는 경우가 많습니다. 그때는 터미널에서 아래 한 줄을 실행해 `python` 으로도 불리게 합니다.

```
sudo ln -s "$(command -v python3)" /usr/local/bin/python
```

## 설치

터미널에서 아래 두 명령을 한 줄씩 따로 실행합니다. 첫 줄이 성공한 뒤 둘째 줄을 실행합니다.

```
claude plugin marketplace add yehsb123/no-ai
claude plugin install no-ai@no-ai
```

Claude Code 입력창에서 해도 됩니다. `/plugin marketplace add yehsb123/no-ai` 를 보내고, 끝나면 `/plugin install no-ai@no-ai` 를 따로 보냅니다. 두 줄을 한 번에 붙여 넣으면 한 명령으로 읽혀 설치되지 않습니다.

설치가 끝나면 Claude Code를 닫았다가 다시 엽니다. `/no-ai:on` 을 입력해 "NO-AI 켜짐"이 나오면 준비가 끝났습니다.

## 쓰는 법

따로 입력할 명령은 없습니다. 평소처럼 한국어 글을 부탁하면 됩니다. Claude가 글을 쓰기 전에 누가 읽는지, 어디에 붙여 넣는지부터 확인하고, 글의 종류에 맞는 규칙으로 쓴 뒤 검사까지 합니다.

```
이번 주 배포 내용 팀 노트로 써줘
고객사에 보낼 일정 변경 메일 초안 써줘
랜딩페이지 첫 화면 문구 다시 써줘
방금 고친 내용 커밋해줘
```

노트, 칸반, 회의록, 고객 메일, 메신저, 커밋과 PR, README, 랜딩페이지와 SaaS 화면, 교안, 발표 자료, 이력서와 자기소개서, 홍보 글, 번역, 블로그 글, 채팅 답변에 적용됩니다.

## 켜고 끄기

명령은 두 개뿐입니다.

- `/no-ai:on` 켜기
- `/no-ai:off` 끄기

한 번 바꾸면 세션을 새로 열어도 그대로이고, 그 PC의 모든 세션에 적용됩니다.

## 업데이트 받기

규칙은 계속 고쳐지고, 새 규칙은 따로 할 일 없이 자동으로 받습니다. Claude Code를 켤 때 여섯 시간에 한 번 새 규칙이 있는지 확인하고, 받은 규칙은 다음에 켤 때부터 적용됩니다.

지금 바로 받으려면 터미널에서 `claude plugin marketplace update no-ai` 와 `claude plugin update no-ai@no-ai` 를 차례로 실행하고 Claude Code를 다시 엽니다.

## 규칙 제안

쓰다가 규칙에 없던 AI 말투를 찾았거나 규칙끼리 겹치는 곳을 보면 Claude에게 "이 표현 NO-AI 규칙으로 제안해줘"라고 말합니다.

Claude가 기존 규칙과 겹치는지 보고, 겹치면 기존 규칙을 고치는 쪽으로 제안을 정리합니다. 바뀌는 내용을 보여 주고 허락을 받은 뒤 내 GitHub 계정으로 제안을 올리고 링크를 줍니다.

링크를 열어 Create pull request 를 누르면 끝납니다. 요청 원문, 고객사, 동료 이름, 파일 내용은 제안에 넣지 않습니다.

처음 한 번은 터미널에서 `gh auth login` 으로 GitHub에 로그인해 둡니다. 저장소 관리자가 제안을 합치면 설치한 사람 모두에게 업데이트로 갑니다.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| `/no-ai:on` 이 없는 명령이라고 나옵니다 | 설치 뒤 다시 열지 않았습니다. Claude Code를 다시 열거나 `/reload-plugins` 를 입력합니다 |
| `marketplace add` 가 실패합니다 | git이 없거나 인터넷이 막혀 있습니다. 터미널에서 `git --version` 을 확인합니다 |
| 설치가 안 됩니다 | 두 명령을 한 번에 붙여 넣었을 수 있습니다. 한 줄씩 따로 실행합니다 |
| 켜져 있는데 규칙이 적용되지 않는 것 같습니다 | `python` 명령이 없으면 훅이 돌지 않습니다. 준비의 Python 항목을 확인합니다 |
| 새 규칙이 들어오지 않습니다 | 마지막 확인 뒤 여섯 시간이 지나지 않았거나 `claude` 명령을 찾지 못했습니다. 업데이트 받기의 명령으로 직접 받습니다 |
| "설치된 플러그인 사본이라 고치지 않습니다"가 나옵니다 | 설치된 규칙 파일은 고칠 수 없습니다. 규칙 제안으로 올립니다 |
| "NO-AI 규칙은 한 곳에만 둡니다"가 나옵니다 | NO-AI로 시작하는 이름의 파일을 만들려 했습니다. 다른 이름을 씁니다 |

그래도 안 되면 터미널에 나온 오류 문구를 저장소 관리자에게 보냅니다.

## 지우기

`claude plugin uninstall no-ai@no-ai` 를 실행합니다. 꺼 둔 적이 있으면 사용자 폴더의 `.claude/.no-ai-off` 파일도 지웁니다.
