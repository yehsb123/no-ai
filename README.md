# NO-AI

Claude Code가 한국어 글을 쓸 때 AI 티를 빼도록 하는 플러그인입니다. 설치하면 켜진 상태로 시작해서 처음에 켤 일은 없습니다. 쓰지 않으려면 `/no-ai:off` 로 끕니다.

## 준비

- Claude Code
- git
- Python 3. 터미널에서 `python --version` 을 쳤을 때 버전이 나와야 합니다.

Windows에서 Python을 새로 설치할 때는 설치 첫 화면의 "Add python.exe to PATH"를 체크합니다. Mac은 `python3` 만 있는 경우가 많습니다. 그때는 터미널에서 아래 한 줄을 실행해 `python` 으로도 불리게 합니다.

```
sudo mkdir -p /usr/local/bin
sudo ln -s "$(command -v python3)" /usr/local/bin/python
```

## 설치

3단계입니다. 1번과 2번은 한 줄씩 따로 실행하고, 앞 단계가 성공한 뒤 다음 단계로 넘어갑니다.

1. 터미널에서 마켓플레이스를 추가합니다.
   ```
   claude plugin marketplace add yehsb123/no-ai
   ```
2. 이어서 플러그인을 설치합니다.
   ```
   claude plugin install no-ai@no-ai
   ```
3. Claude Code를 닫았다가 다시 엽니다. 열 때 "NO-AI가 켜져 있습니다"가 보이면 끝입니다.

설치한 창에서는 다시 열기 전까지 규칙이 적용되지 않습니다. 다시 열지 않고 바로 쓰려면 입력창에 `/reload-plugins` 를 입력합니다.

1번과 2번은 Claude Code 입력창에서 `/plugin marketplace add yehsb123/no-ai`, `/plugin install no-ai@no-ai` 로 해도 됩니다. 두 줄을 한 번에 붙여 넣으면 한 명령으로 읽혀 설치되지 않습니다.

## 쓰는 법

따로 입력할 명령은 없습니다. 평소처럼 한국어 글을 부탁하면 됩니다. Claude가 글을 쓰기 전에 누가 읽는지, 어디에 붙여 넣는지부터 확인하고, 글의 종류에 맞는 규칙으로 쓴 뒤 검사까지 합니다.

```
이번 주 배포 내용 팀 노트로 써줘
고객사에 보낼 일정 변경 메일 초안 써줘
랜딩페이지 첫 화면 문구 다시 써줘
방금 고친 내용 커밋해줘
```

팀 노트, 고객 메일, 커밋, 화면 문구, 교안, 블로그 글, 채팅 답변처럼 한국어로 쓰는 글 전부에 적용됩니다. 글 종류별 규칙은 `적용.md` 의 도메인 표에 있습니다.

## 켜고 끄기

처음에는 켜져 있습니다. 끄려면 `/no-ai:off`, 다시 켜려면 `/no-ai:on` 을 입력합니다.

한 번 끄면 세션을 새로 열어도 꺼진 채로 남고, 그 PC의 모든 세션에 적용됩니다. 세션을 열 때마다 지금 켜져 있는지 꺼져 있는지 한 줄로 보여 줍니다.

꺼도 규칙 사본을 고치지 못하게 막는 기능과 자동 업데이트는 계속 돕니다.

## 업데이트 받기

따로 할 일은 없습니다. 켜 둔 상태에서 요청을 보내면 많아야 다섯 분에 한 번 뒤에서 새 규칙을 받고, 그다음 요청부터 적용됩니다. 쓰고 있던 세션을 껐다 켤 필요가 없습니다.

훅이나 명령처럼 플러그인 자체가 바뀐 경우는 6시간에 한 번 받고, 다음에 Claude Code를 켤 때 적용됩니다. 지금 바로 받으려면 터미널에서 `claude plugin marketplace update no-ai` 와 `claude plugin update no-ai@no-ai` 를 차례로 실행하고 Claude Code를 다시 엽니다. 이 두 명령이 실패하면 `claude plugin marketplace remove no-ai` 를 실행한 뒤 설치의 1번과 2번을 다시 합니다.

## 규칙 제안

쓰다가 규칙에 없던 AI 말투를 찾았거나 규칙끼리 겹치는 곳을 보면 Claude에게 "이 표현 NO-AI 규칙으로 제안해줘"라고 말합니다.

Claude가 기존 규칙과 겹치는지 보고, 겹치면 기존 규칙을 고치는 쪽으로 제안을 정리합니다. 바뀌는 내용을 보여 주고 허락을 받은 뒤 내 GitHub 계정으로 제안을 올리고 링크를 줍니다.

링크를 열어 Create pull request 를 누르면 끝납니다. 요청 원문, 고객사, 동료 이름, 파일 내용은 제안에 넣지 않습니다.

처음 한 번은 터미널에서 `gh auth login` 으로 GitHub에 로그인해 둡니다. 저장소 관리자가 제안을 합치면 설치한 사람 모두에게 업데이트로 갑니다.

## 문제가 생기면

| 증상 | 원인과 해결 |
|---|---|
| 세션을 열어도 "NO-AI가 켜져 있습니다"가 안 보이거나 `/no-ai:off` 가 없는 명령이라고 나옵니다 | 설치 뒤 다시 열지 않았습니다. Claude Code를 다시 엽니다. `/reload-plugins` 로 불러온 창에서는 이 문구가 나오지 않을 수 있지만 명령 목록에 `/no-ai:off` 가 보이면 설치된 상태입니다 |
| `marketplace add` 가 실패합니다 | git이 없거나 인터넷이 막혀 있습니다. 터미널에서 `git --version` 을 확인합니다 |
| 설치가 안 됩니다 | 두 명령을 한 번에 붙여 넣었을 수 있습니다. 한 줄씩 따로 실행합니다 |
| 다시 열어도 켜짐 문구가 안 보이거나 규칙이 적용되지 않는 것 같습니다 | `python` 명령이 없으면 훅이 돌지 않습니다. 준비의 Python 항목을 확인합니다 |
| "NO-AI가 꺼져 있습니다"가 보입니다 | 예전에 끈 기록이 남아 있습니다. `/no-ai:on` 을 입력합니다 |
| 새 규칙이 들어오지 않습니다 | 마지막으로 받은 지 다섯 분이 안 됐거나 git이 저장소에 닿지 못했습니다. 사용자 폴더의 `.claude/no-ai-live` 폴더와 `.claude/.no-ai-pulled` 파일을 지우면 다음 요청 때 새로 받고, 그다음 요청부터 적용됩니다 |
| "설치된 플러그인 사본이라 고치지 않습니다"가 나옵니다 | 설치된 규칙 파일은 고칠 수 없습니다. 규칙 제안으로 올립니다 |
| "자동으로 받아 온 규칙 사본이라 고치지 않습니다"가 나옵니다 | 5분마다 새로 받는 규칙 사본이라 고쳐도 사라집니다. 규칙 제안으로 올립니다 |
| "NO-AI 규칙은 GitHub yehsb123/no-ai 저장소 한 곳에만 둡니다"가 나옵니다 | NO-AI로 시작하는 이름의 문서를 만들려 했습니다. 다른 이름을 씁니다 |

그래도 안 되면 터미널에 나온 오류 문구를 저장소 관리자에게 보냅니다.

## 지우기

`claude plugin uninstall no-ai@no-ai` 와 `claude plugin marketplace remove no-ai` 를 차례로 실행합니다. 사용자 폴더의 `.claude` 안에 남는 `no-ai-live` 폴더와 `.no-ai-off`, `.no-ai-pulled`, `.no-ai-updated` 파일도 지웁니다.
