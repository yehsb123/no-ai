# 번역

영어나 다른 외국어 원문을 한국어로 옮길 때 적용한다.

## T01 번역투 표현

| 금지 | 대신 |
|---|---|
| ~되어지다 | ~되다 |
| ~에 있어서 | ~에서 |
| ~을 가지고 있습니다 (have) | ~이 있습니다 |
| 좋은 하루 가지세요 | 좋은 하루 보내세요 |
| 하나의 방법입니다 (a) | 방법입니다 |
| 그것은, 그들은 (반복되는 대명사) | 가리키는 대상 이름을 쓰거나 뺀다 |

검사: 줄 `되어지|에 있어서|을 가지고 있습니다|를 가지고 있습니다|하나의`

## T02 영어 어순

긴 수식어를 명사 앞에 쌓지 않는다. 원문 한 문장이 한국어로 길어지면 두 문장으로 나눈다.

## T03 이름과 용어

사람 이름, 회사 이름, 제품 이름은 원문 표기를 그대로 둔다. 용어는 C26을 따른다.

## T04 원문과 다른 내용

원문에 없는 설명을 더하지 않는다. 옮기지 않고 뺀 부분이 있으면 무엇을 뺐는지 번역 뒤에 따로 적는다.
