# 메신저

## M01 문의 글

    답을 받으려는 글을 확정형으로 쓰기 ("SO-101로 정했습니다")
    아는 사람에게 보내는 글에 회사 소개 붙이기
    알아본 범위를 밝히지 않고 조언 구하기
    메신저에 문서처럼 빈 줄 넣기
    직접 쓸 장비인지 팔 상품인지 흐리기

자문을 구하는 글은 열어 둔다 ("SO-101 쪽을 보고 있는데 혹시 추천하시는 제품이 있을까요"). 알아본 범위를 먼저 적는다 ("SO-101, PiPER, xArm 6까지는 비교해 봤습니다"). 묻는 내용은 사용자가 궁금하다고 한 것까지만 쓰고, "다른 추천 제품도 알려 줘"처럼 요청에 없는 부탁을 더하지 않는다.

직접 쓸 장비인지 팔 상품인지는 첫 문장에 "교육용으로 직접 쓰려고 알아보는 중입니다"처럼 넣는다. "팔 상품이 아니라" 같은 대조는 붙이지 않는다. 메신저는 빈 줄 없이 이어서 보낸다.

## M02 관계에 맞춘 말투

친한 사람에게 보내는 카톡에는 "염치 불구하고", "번거롭게 해드려 죄송합니다" 같은 격식 인사를 넣지 않는다. "스펙표는 다 뽑아봤는데 실제로 써보면 다를 것 같아서요", "감이 전혀 안 잡히네요 ㅠ"처럼 사용자가 평소 쓰는 말투로 쓴다.

요청에 친한 동료, 동기, 친구처럼 편한 사이라고만 나오고 사용자 말투를 알 수 없으면 반말로 쓴다 ("오랜만이야! 하나만 물어봐도 될까?"). "여쭤볼게요" 같은 높임은 실무 판정에서 "격식을 차렸다"는 평을 받았다.

## M03 대신 쓰는 메시지

사용자 대신 쓰는 메시지와 코멘트는 사용자 말투로 쓴다. 이모지는 C06을 따른다. 사용자 이름으로 다는 코드 리뷰 코멘트도 말투는 이 규칙을, 내용은 K04를 따른다.
