# 예21 이관 일정 메일

도메인: 고객
걸린 규칙: G01 G03

## 고치기 전

```text
안녕하세요, 데이터 이관 일정을 공유드립니다.

[ 이관 일정 ]
11월 18일 시험 이관, 11월 25일 본 이관입니다.

첨부한 점검표는 사내 전용 양식을 그대로 옮긴 참고용 자료입니다.
```

## 고친 뒤

```text
안녕하세요, 데이터 이관 일정을 알려 드립니다.

11월 18일에 시험 이관을 하고, 11월 25일에 본 이관을 합니다. 시험 이관 뒤에 첨부한 점검표로 고객 목록과 주문 내역이 맞는지 확인해 주시면 본 이관을 진행하겠습니다.
```
