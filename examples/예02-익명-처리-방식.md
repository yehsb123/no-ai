# 예02 익명 처리 설명 노트

도메인: 사내문서
걸린 규칙: C01 C14 C19 C22

## 고치기 전

```text
# 4. 익명이 어떻게 지켜지나

이게 이 기능의 핵심입니다.

익명 글은 **공용 계정 하나**로 들어갑니다. 글을 보관하는 쪽에는
"누가 썼는지"가 아예 없습니다. 그래서 이렇게 됩니다.

- 엔진 쪽 데이터를 통째로 열어봐도 익명 글의 작성자를 알 수 없습니다
- 화면에 내려보내는 응답에서 익명 글은 작성자 정보 칸 **자체가 없습니다**.
  비워두지 않습니다 — 비워두면 언젠가 누가 채웁니다
```

## 고친 뒤

```text
# 6. 익명 처리 방식

익명 글은 공용 계정 하나로 저장되고, 진짜 작성자는 따로 적힙니다.
관리자도 작성자를 볼 수 없습니다.
```
