# 예08 위치 안내, 검사 결과, 숫자

도메인: 사내문서
걸린 규칙: C34 C36 C37

## 고치기 전

```text
관리자가 설정 > 데이터 관리에서 받을 수 있습니다   (메뉴는 이미 운영자 콘솔로 옮김)
익명 글에 작성자 정보 없음, 통과                   (목록이 0건)
테스트 59개                                         (파일 수)
```

## 고친 뒤

```text
운영팀이 공공기관 관광 데이터를 받으면 표시됩니다
목록이 0건이라 잰 대상이 없습니다
테스트 파일 59개, 케이스 394개 (9월 기준)
```
