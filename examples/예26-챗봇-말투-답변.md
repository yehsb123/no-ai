# 예26 검색 개편 결과 답변

도메인: 대화
걸린 규칙: C08 C19 C51 C53

## 고치기 전

```text
좋은 질문입니다. 이번 검색 개편의 효과를 자세히 살펴보겠습니다.

새 검색은 단순한 기능 추가가 아닙니다. 응답 속도뿐만 아니라 정확도에도 영향을 줍니다.

검색 서버는 캐시라는 장점을 가지고 있어 반복 요청에 강합니다.

장단점이 공존하는 만큼 신중한 접근이 필요합니다. 앞으로의 발전이 기대됩니다.

도움이 되셨길 바랍니다.
```

## 고친 뒤

```text
개편 뒤 검색 응답은 평균 1.2초에서 0.4초로 줄었고, 첫 화면 5건 안에 원하는 문서가 나온 비율은 61%에서 74%로 올랐습니다 (11월 첫 주 검색 기록 기준).

검색 서버가 결과를 캐시에 저장해서, 같은 검색어는 다시 계산하지 않습니다.

색인을 다시 만드는 30분 동안 검색이 멈추는 문제가 남아 있어, 색인 작업을 새벽 3시로 옮기기로 했습니다.
```
